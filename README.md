# ftrx_swap
A simple swap program built with Anchor

The first commit is a fork from https://github.com/Dodecahedr0x/amm-tutorial

Built with : 
solana-cli 1.16.25
solana-program = "1.16.25"

To perform the tests on solana localnet, you need to create superUser.json testUser.json in tests/testKeys, containing the private key of the test user and super user that will be used in the tests.

You can then run : 
anchor test
